# Hanot Project - Roadmap & Updates

This document tracks the recent improvements and the planned features for the platform.

## ✅ Done (Recent Updates)
- **Bon d'Achat (Purchase Voucher) Overhaul**:
    - Replaced article dropdown with a **Search Modal**.
    - Implemented **Live Search** (updates on every keystroke).
    - Grouped items by product for better visibility.
    - Added quick **Size Management** per product card.
    - Implemented **Duplicate Size Prevention**.
    - Modernized the UI with a clean, card-based layout.
- **POS & Receipt Improvements**:
    - **Real-time Stock**: Stock now updates instantly in the POS after a sale without page refresh.
    - **Better Printing**: Replaced standard browser print with a dedicated professional invoice/ticket layout.
    - **Cancellation with Stock Revert**: Added ability to cancel receipts, which automatically restores the sold items to stock.
- **Supplier Integration**: Added supplier selection and payment tracking to the purchase flow.

## 🚀 Upcoming Features (Roadmap)

### 1. Inventory & Stock Management
- [ ] **Low Stock Alerts**: Automated notifications when a product's quantity falls below a threshold.
- [ ] **Stock History**: View a detailed timeline of every stock movement for a specific item.
- [ ] **Barcode Printing**: Generate and print barcode labels directly from the system.

### 2. Financials & Reporting
- [ ] **Supplier Balances**: Track credits and debts for each supplier automatically.
- [ ] **Detailed Analytics**: Charts for sales trends, most profitable items, and expenses.
- [ ] **PDF Exports**: Generate professional PDF documents for vouchers and receipts.

### 3. POS & Sales
- [ ] **Quick POS**: A touch-optimized interface for faster sales at the counter.
- [ ] **Discount Management**: Apply percentage or fixed-amount discounts per item or per bill.
- [ ] **Multiple Payment Methods**: Support for Cash, Card, and Store Credit in a single transaction.

### 4. System & Integration
- [ ] **Offline Mode**: Allow basic operations (sales) to work without internet and sync later.
- [ ] **Multi-user Permissions**: More granular control over what employees can see and do.
- [ ] **Image Gallery**: Support for multiple high-quality images per product with a zoomable viewer.
